A/B probabilistic reproductions, and their tests/tooling. It is not used by the
active experiment runner or regenerated notebooks. Its numbers use different
units and channel assumptions and must not be merged with ns-3 measurements.

For historical reproduction, work from this directory so `src` and
`experiments` resolve to the archived packages. Dependencies are recorded in
`requirements.txt`. The original senior notebook remains in
`../../colab/senior_code_original.ipynb` and `../../project_docs/senior_code.ipynb`.
